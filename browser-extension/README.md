# Referral Copilot - Conector LinkedIn

Extensão Manifest V3 para Chrome e Edge. A coleta roda no navegador do próprio usuário, usando apenas a página visível de conexões. A extensão não lê, armazena ou transmite senhas e cookies.

## Instalação interna

1. Abra `chrome://extensions` ou `edge://extensions`.
2. Ative o modo do desenvolvedor.
3. Extraia o ZIP e selecione **Carregar sem compactação**.
4. Na plataforma, abra **Minha rede** e clique em **Conectar LinkedIn**. Uma nova aba será aberta para o login normal; depois disso, a sincronização continua e retorna ao app automaticamente.

Para distribuição externa, publique esta pasta na Chrome Web Store e restrinja a extensão à organização.
